v0.5.1 pre-release ↗Explore source codeDevelopment setup
Experimental developer pre-releases are available on GitHub. The latest published preview is v0.5.1, with an unsigned Windows x64 developer EXE and SHA-256 checksum. It is not a self-contained installer; separate Python 3.11, authorized Chatterbox model dependencies/weights and WebView2 are required. Real Hindi listening, distinct voices and clean-machine Windows usage remain unverified. View verified GitHub releases ↗

RELEASE READINESS

Validate before sharing

The v0.5.1 source includes model-free diagnostics and simulated UI tests, not proven Hindi speech quality. Before declaring production readiness, use the manual Windows/Hindi acceptance checklist, record the model and hardware actually used, and inspect the generated WAV by ear. The acceptance issue remains open.
