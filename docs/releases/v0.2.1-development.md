## Implemented in source (subject to CI)

- Unicode-aware, project-local pronunciation overrides and non-model text preview.
- Optional glossary in existing v2 project format; Python, TypeScript and Rust validation; preserved v0.2.0 compatibility.
- Editable reviewed spoken text distinct from untouched original script.
- Content-based cache invalidation when effective text changes; validated cached PCM16 WAV metadata.
- Genuine single-segment selection and force-retry WAV rendering without synthesizing neighboring dialogue.
- Rust subprocess stdout is now read concurrently under a bounded response limit rather than waiting for the worker to exit before draining its pipe; embedded build-machine inference paths were removed.
- New desktop pronunciation management and model-independent environment doctor checks.
- More explicit parse replacement confirmation and render revision/unmount cleanup.
- Python/TS/Rust regressions and a guarded, exact-SHA v0.2.1 manual release workflow.
- Correction of the obsolete v0.2.0 publish trigger and release-status documentation.

## What the source does not guarantee

Human listening was **not performed** by this change. Chatterbox model weights and devices were not provided. There is no verified distinct-character acoustic identity. The unsigned Windows EXE is **not** a standalone TTS installer; Python 3.11, inference source, compatible dependencies, licensed weights and WebView2/Tauri prerequisites remain separately required. The current workflow can verify compilation and SHA256, but not interactive startup on a clean Windows computer.
