# KathaSvara v0.5.5 — experimental preview manual publication gate

**NOT PUBLISHED / NOT STABLE.** This checklist is for an **unsigned, unbundled developer EXE**. Passing source CI or a Windows candidate build never constitutes a published tag, complete installer, genuine Hindi audio or successful end-user experience. [Issue #3](https://github.com/sanskarIN/KathaSvara/issues/3) tracks manual real-Hindi/Windows acceptance.

## Before manual dispatch

- [ ] Confirm predecessor [v0.5.4](https://github.com/sanskarIN/KathaSvara/releases/tag/v0.5.4) remains an immutable published experimental prerelease with its three assets.
- [ ] Review model-free WAV diagnostics (merged [PR #126](https://github.com/sanskarIN/KathaSvara/pull/126)), in-app session runtime selection ([PR #128](https://github.com/sanskarIN/KathaSvara/pull/128)) and this v0.5.5 version-sync PR.
- [ ] Verify `0.5.5` across package.json, root package-lock, tauri.conf.json, Cargo.toml and Python pyproject.toml; check candidate EXE naming and release-safe notes.
- [ ] Merge the reviewed release preparation into protected `main` and require exact-main Python, React, Windows Rust, Windows Python-lock and candidate EXE success.
- [ ] Confirm neither v0.5.5 tag nor published v0.5.5 GitHub Release exists.
- [ ] Record full current `main` 40-character commit SHA **after** merge. Do not reuse a PR head SHA.

## Exact-SHA manual publication

- [ ] An authorized maintainer intentionally runs [release-v0.5.5.yml](https://github.com/sanskarIN/KathaSvara/actions/workflows/release-v0.5.5.yml) on branch `main` and enters that exact SHA as `release_sha`.
- [ ] Freeze `main` during the build and require all seven jobs (`prepare`, `python`, `frontend`, `rust-windows`, `windows-python-lock`, `windows-exe`, `publish`) to conclude **success**.
- [ ] Verify tag matches dispatch SHA, `prerelease=true`, `draft=false` and exactly three nonempty assets: `KathaSvara-v0.5.5-dev-win64.exe`, `README.txt`, `SHA256SUMS.txt`.
- [ ] Confirm successful SHA-256 validation of the EXE downloaded **from the published GitHub release**, and that its live release description uses `v0.5.5-published-notes.md` without a false draft banner.
- [ ] Only then update public README, website, QA latest-release references and static version tests in a separate passing reviewed PR. Do **not** move historical tags.

## Still independent, not passed

- [ ] Real Chatterbox model loading with separately approved Python dependencies and checkpoint weights.
- [ ] Human listening for intelligible Hindi, naturalness and consistent narration.
- [ ] Tested character/scene renders with actual WAV/SRT exports.
- [ ] Clean Windows 11 install/launch with appropriate OS security settings and no hidden model download.

These items remain open in [#3](https://github.com/sanskarIN/KathaSvara/issues/3) and [#129](https://github.com/sanskarIN/KathaSvara/issues/129). Do not label the preview stable or self-contained.
