# KathaSvara v0.5.6 — Hindi Speech Readiness and Listening Developer Preview

> **DRAFT — NOT PUBLISHED / NOT STABLE.** This source plan is not a GitHub Release or a claim that real Hindi audio has been heard. The latest publicly verified experimental preview remains [v0.5.5](https://github.com/sanskarIN/KathaSvara/releases/tag/v0.5.5).

## Proposed changes since v0.5.5

- **One-click speech readiness (without model):** a guided Settings action checks Python, disposable PCM16 WAV plumbing and optional speech imports in order, with fixed and privacy-safe next steps. A green check never proves usable Hindi speech.
- **Verified session runtime:** select a trusted Python 3.11 interpreter and matching `kathasvara-inference` package/source version for new jobs. Failed or timed-out checks do not discard the previous selection. Source metadata checks are bounded; they are not a signature/authenticity guarantee.
- **Explicit real Hindi model test:** with a separate unchecked-by-default consent, synthesize a short original Hindi sample through the actual local model, inspect WAV structure and signal warnings, listen, export the test file or delete it. **First use may download large third-party model weights** and use significant compute/storage. Neither source CI nor readiness diagnostics initiates those model downloads.
- **Safer audio lifecycle:** keep verified WAVs available when embedded playback fails; catch stale dialogs and export/deletion replies; redact private/native errors; run bounded native WAV copies on a background worker with no-overwrite rules.
