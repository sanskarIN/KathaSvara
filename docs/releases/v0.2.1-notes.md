# KathaSvara v0.2.1 — Experimental developer pre-release

**कथास्वर — Give Every Story a Voice.**

This is an **experimental local-first developer preview**, not a stable release or an independent Windows Hindi voice product.

## What's new

- A per-project Hindi pronunciation glossary for names, archaic words, places, and mixed Hindi/English phrases. Add, edit, disable, search and delete reversible text replacements.
- Review original script, manually reviewed dialogue and the exact preprocessed text the Python synthesizer receives. No actual model is loaded for text preview.
- Edit reviewed spoken text without modifying the original story script.
- More conservative reusable segment cache validation; unchanged effective speech can reuse a previous cache entry after unrelated glossary edits.
- Render or force-retry just one selected spoken line as its own WAV, or force re-render the entire story. Job progress still reports completed segment totals and cancellation is cooperative.
- Redacted, no-download Python/inference path and local write diagnostics.
- Fix a potential Python subprocess pipe deadlock for larger JSON responses and remove embedded build-machine paths from the Windows executable.
- Additional Python, TypeScript and Rust compatibility tests and guarded v0.2.1 publication workflow.

## Fixes, migration, and privacy

- Previously saved v0.2.0 schema v2 documents without the optional glossary remain readable. Legacy v0.1.x project files are stored separately and not overwritten during conversion.
- Better protection against exporting stale combined audio, unexpected result arrival after edits and invalid cached WAV files.
- Script, glossary and locally generated audio stay on the machine. No cloud transcription, telemetry, or voice cloning is provided by the app. The software still uses external open-source dependencies under their separate terms.

## Windows asset and SHA-256

Attached by the [successful gated release workflow](https://github.com/sanskarIN/KathaSvara/actions/runs/39370507279), `KathaSvara-v0.2.1-dev-win64.exe` is an **unsigned, unbundled Windows x64 developer executable**, **NOT AN INSTALLER**. It contains no Python runtime, Chatterbox weights or managed models. See `README.txt` before executing and check its bytes against `SHA256SUMS.txt` using Windows `Get-FileHash` or another trusted SHA-256 tool. Do not turn off Windows security protections to run untrusted binaries.

Required separately: Windows/Tauri WebView2 prerequisites, compatible Python 3.11, configured `KATHASVARA_PYTHON` and `KATHASVARA_INFERENCE_DIR`, installable model dependencies, appropriate hardware and user-approved separately obtained model weights. See [Windows setup](https://github.com/sanskarIN/KathaSvara/blob/main/docs/installation/portable-windows-candidate.md).

## Limits and what has *not* been verified

Distinct character voices and speaker conditioning are **not confirmed**. Cast assignments are storytelling roles routed through supported expressiveness and CFG controls; they are not independently identifiable voices. Pitch/speed/SSML, soundtrack mixing, voice cloning and self-contained model packaging are not supported.

Per render: at most 256 speech segments, 100,000 spoken characters, 500 chunks and 20 minutes of composed WAV. Desktop audio preview is capped at 25 MiB. Cancellation is cooperative between inference chunks. Model identifier and revision must be checked separately before claiming exact reproducibility.

Unit tests with a simulated engine verify assembly and cache logic **but do not test real Hindi narration**. Clean Windows GUI startup, Hindi listening quality, actual model revision/hardware, and recovery of interrupted inference on consumer devices remain **manual acceptance tasks**. See [issue #3](https://github.com/sanskarIN/KathaSvara/issues/3). Refer to the [v0.2.1 development tracker](https://github.com/sanskarIN/KathaSvara/blob/main/docs/releases/v0.2.1-development.md) and the release workflow's execution log for exact automated check outcomes; do not infer anything from the mere existence of assets.
