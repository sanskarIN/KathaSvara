# KathaSvara v0.2.0 — Experimental Developer Pre-release

> **Early-access engineering preview — NOT a stable release or verified narration product.**
> v0.2.0 introduces a multi-character story **structure and synthesis-routing foundation**, not independently verified distinct-character voices.

## What's new since v0.1.1

- **Characters & reusable voice settings:** Create and duplicate character profiles, configure only engine-supported Hindi expressiveness and CFG guidance parameters, delete with explicit narrator reassignment.
- **Scene editor:** Create/rename/reorder scenes, move dialogue between scenes, review parsed dialogue before rendering, keep text and schema v2 data locally.
- **Deterministic Hindi dialogue parser:** Recognizes explicitly named speakers (e.g., `राजा भोज:`), narrator paragraphs, Markdown scene headings and bracketed stage directions. Unknown speakers are displayed for **manual assignment**; automatic identity inference is not claimed.
- **Protected existing stories:** Versioned schema v2 and atomic project writes use a separate `projects-v2` folder, preserving the original v0.1.x project format.
- **Experimental multi-segment PCM16 WAV synthesis:** Sequential chunk processing through the genuine Chatterbox Multilingual adapter; per-segment supported parameters, bounded chunking, cached results, selectable scenes, selective regeneration, sample-based duration reporting, pauses and waveform-edge fades.
- **Local progress and cancellation:** The desktop polls segment-progress state. A cancellation request is handled *between* inference chunks, not immediately during a synchronous model call.
- **Development tests:** Python/Ruff/pytest, React/TypeScript build and tests, Windows Rust unit tests/Clippy, plus deterministic **mock-audio** tests for render ordering and cache correctness.

## Windows executable asset — experimental and NOT standalone

The attached **`KathaSvara-v0.2.0-dev-win64.exe`** is an **unsigned Tauri application binary** built by Windows GitHub Actions from the tagged release source. It is NOT an installer. It does NOT contain Python, Chatterbox, model weights, an inference environment, a signed certificate or an auto-updater. Opening the interface does **not** prove voice generation is functional.

Before testing the desktop, developers must configure:

- A compatible Python 3.11 environment with KathaSvara and Chatterbox speech dependencies.
- `KATHASVARA_PYTHON` — absolute path to that Python executable.
- `KATHASVARA_INFERENCE_DIR` — absolute path to the checked-out `services/inference` directory.
- Model weights downloaded separately according to upstream licensing and hardware requirements.
- Compatible Windows WebView2 support and any other system prerequisites.

Read the attached **`README.txt`** and the [development setup guide](../installation/development.md). Verify `SHA256SUMS.txt` for the executable. As it is unsigned and unvalidated on a clean end-user machine, **do not disable Windows security checks** just to launch it.

GitHub's automatic **Source code (zip)** and **Source code (tar.gz)** archives are also provided.

## Important limitations and unverified behavior

1. **Distinct character voices are not demonstrated.** The shipped pathway currently routes supported controls through one underlying model. Separate speaker identities, reference-audio consent workflows and voice consistency require further implementation and real tests.
2. **Actual Hindi listening quality has not been accepted.** Pronunciation, pacing, speaker continuity, long-story render quality and WAV export need in-person/real-hardware verification. Synthetic test samples are not actual model speech.
3. **No clean Windows install or GUI end-to-end acceptance** is recorded. Binary compilation succeeded previously as a CI artifact, but integration on end-user computers remains experimental.
4. **Large stories remain bounded** by current per-render and desktop WAV preview size limits; the app is not a full DAW or production audiobook editor.
5. **Cancellation is cooperative**, and an ongoing opaque model-generation call may continue until it returns. The GUI does not yet support all advanced retry/recovery controls.
6. Pronunciation dictionary UI, reference-voice licensing/consent management, fully packaged runtime, signed installers and all commercial-production safeguards are not complete.

## Getting started

1. Download the source archive or clone `https://github.com/sanskarIN/KathaSvara` and check out `v0.2.0`.
2. Follow [development installation](../installation/development.md); install Node.js, Rust/Tauri and Python 3.11 dependencies.
3. For a no-download check, run `echo '{"action":"diagnose"}' | python -m kathasvara.cli` in `services/inference`.
4. Write explicitly labeled dialogue (for example `राजा भोज: नमस्कार।`), create matching characters and manually resolve unknown speakers.
5. Test with compatible local model weights. Verify any actual narration by listening and inspecting the WAV before relying on it.
