## Known limitations

The native app is not built or validated in this environment. The Python process reloads the model per generation request; future versions should retain a supervised persistent inference worker and add cancellation. Script generation is currently limited to 3000 Unicode code points per job; long-form audiobook processing, voice cloning, reference audio and music mixing are not part of this milestone. Output audio is generated locally; no model weights are bundled.
