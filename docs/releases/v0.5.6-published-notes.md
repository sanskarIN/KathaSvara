# KathaSvara v0.5.6 — Hindi Speech Readiness and Listening Developer Preview

**Experimental pre-release — NOT STABLE.** The Windows executable is **UNSIGNED and UNBUNDLED**, **NOT A COMPLETE INSTALLER**. The Python speech environment and model weights are not bundled.

## What's new since v0.5.5

- **Guided no-model readiness:** one Settings action checks Python, disposable PCM WAV I/O and optional TTS imports, with privacy-safe repair guidance.
- **Validated local speech runtime:** choosing Python must pass a bounded Python 3.11 check; inference source package name/version must match this desktop build. Failed selection preserves the earlier session choice. This does not install TTS dependencies.
- **Opt-in real Hindi smoke test:** a separate user-consented short Hindi sample can load an authorized local speech model, create a real WAV, inspect its PCM structure and signal warnings, and offer playback, export or local deletion. Model initialization **may download large third-party model weights**; users must approve/check license, storage, network and hardware before running.
- **Playback and export safeguards:** safe handling of failed embedded playback and stale results, stricter native WAV checks, no-overwrite exports off the UI thread, and sanitized native error messages.
- **Regression checks:** Python, React and Windows Rust/model-free tests protect flow and build integrity. Passing them is not evidence of acceptable Hindi audio.

## Release companions

- `KathaSvara-v0.5.6-dev-win64.exe` — unsigned Windows x64 developer executable, **NOT A COMPLETE INSTALLER**.
- `README.txt` — setup, security, dependency and third-party licensing disclosures.
- `SHA256SUMS.txt` — checksum for downloaded developer EXE.

The EXE does **not** contain Python 3.11, NumPy, SoundFile, PyTorch, Chatterbox Multilingual or compatible model weights. Independently obtained/approved dependencies and compatible hardware are still required.
