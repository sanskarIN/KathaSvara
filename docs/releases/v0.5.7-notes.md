# KathaSvara v0.5.7 — Offline Hindi STT Developer Preview

> **DRAFT — NOT PUBLISHED / NOT STABLE.** The latest public experimental
> prerelease is [v0.5.6](https://github.com/sanskarIN/KathaSvara/releases/tag/v0.5.6).

## Planned changes after v0.5.6

- Explicit offline Hindi STT from a user-selected mono PCM16 WAV (up to
  60 seconds/6 MiB) or a consented short microphone sample (30-second cap),
  with independently installed multilingual faster-whisper/CTranslate2.
- No-model STT setup/WAV checks, fixed path-safe errors, rejection of
  incomplete/English-only models and a changed source recording.
- Bounded private temporary WAV recovery, microphone permission cancellation
  and separate user-initiated recognition.
- Local editable Hindi transcript review before copying text to a story,
  contingent on the separate review PR passing and merging.

## External dependencies and acceptance

**NOT A COMPLETE INSTALLER. NOT STABLE. UNSIGNED and UNBUNDLED.**
The future `KathaSvara-v0.5.7-dev-win64.exe` does not include Python 3.11,
Chatterbox, faster-whisper, model weights or a managed Windows installer.
TTS packages/weights **may download** only after explicit consent and license
review; local STT never automatically downloads recognition weights.
Code checks and an EXE build cannot establish real Hindi intelligibility,
correct words, distinct voices, WebView2 microphone access or clean Windows
installation. Human acceptance is still open in
[issue #3](https://github.com/sanskarIN/KathaSvara/issues/3),
[STT #142](https://github.com/sanskarIN/KathaSvara/issues/142) and
[Windows activation #129](https://github.com/sanskarIN/KathaSvara/issues/129).

## Manual publication only

The owner must separately approve an exact current 40-character `main` SHA
after integration and CI review. Only then may the guarded
[release-v0.5.7.yml](../../.github/workflows/release-v0.5.7.yml) be manually
dispatched. It checks the immutable published v0.5.6 predecessor, all seven
jobs, three nonempty assets, tag/source SHA and downloaded SHA-256 integrity.
Creating this file or merging a source PR cannot publish a release.
