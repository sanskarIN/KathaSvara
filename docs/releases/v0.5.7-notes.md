# KathaSvara v0.5.7 — Offline Hindi STT Developer Preview

> **DRAFT — NOT PUBLISHED / NOT STABLE.** The latest public experimental
> prerelease is [v0.5.6](https://github.com/sanskarIN/KathaSvara/releases/tag/v0.5.6).

## Planned changes after v0.5.6

- Explicit offline Hindi STT from a user-selected mono PCM16 WAV (up to
  60 seconds/6 MiB) or a consented short microphone sample (30-second cap),
  with independently installed multilingual faster-whisper/CTranslate2.
- No-model STT setup/WAV checks, fixed path-safe errors, rejection of
  incomplete/English-only models and a changed source recording.
- Bounded private temporary WAV recovery, microphone permission cancellation
  and separate user-initiated recognition.
- Local editable Hindi transcript review before copying text to a story,
  merged through reviewed PR #166 into protected main.
- Read-only Windows candidate diagnostics check the unsigned EXE's x64 PE
  header, same-artifact SHA-256 and WebView2 Runtime registration, without
  launching the app or changing registry state ([PR #168](https://github.com/sanskarIN/KathaSvara/pull/168)).
- Native Python source selection rejects stale verification workers after
  clearing or replacing the session runtime ([PR #169](https://github.com/sanskarIN/KathaSvara/pull/169)).
- An explicit `-VerifyHindiSttWav` source helper exercises a separately
  installed local multilingual model on a user-selected WAV, even without
  the Windows desktop UI; it returns only a redacted recognition summary,
  **not** the transcript or any claim of Hindi accuracy
  ([PR #170](https://github.com/sanskarIN/KathaSvara/pull/170)).
- Changing or clearing the Python runtime now retires STT consent, microphone
  capture, review drafts and old preflight results so a late previous-runtime
  response cannot restore old recognized text
  ([PR #171](https://github.com/sanskarIN/KathaSvara/pull/171)).

## External dependencies and acceptance

**NOT A COMPLETE INSTALLER. NOT STABLE. UNSIGNED and UNBUNDLED.**
The future `KathaSvara-v0.5.7-dev-win64.exe` does not include Python 3.11,
Chatterbox, faster-whisper, model weights or a managed Windows installer.
TTS packages/weights **may download** only after explicit consent and license
review; local STT never automatically downloads recognition weights.
Code checks and an EXE build cannot establish real Hindi intelligibility,
correct words, distinct voices, WebView2 microphone access or clean Windows
installation. Human acceptance is still open in
[issue #3](https://github.com/sanskarIN/KathaSvara/issues/3),
[STT #142](https://github.com/sanskarIN/KathaSvara/issues/142) and
[Windows activation #129](https://github.com/sanskarIN/KathaSvara/issues/129).

## Human Windows 11 acceptance still pending

Run the [unexecuted v0.5.7 Windows/STT acceptance matrix](../qa/windows-v057-stt-manual-acceptance.md)
with a trusted unsigned candidate, Python 3.11, appropriate separately
licensed model files and a consensually recorded Hindi sample. Record real
device observations before marking any item passed. A green checksum,
WebView2 registry hint or no-model CI result does not prove the UI launches,
microphone permission works, recognizable Hindi is returned or WAV playback
is intelligible. The source-only STT smoke helper deliberately suppresses
recognized words, so human transcript accuracy requires the desktop's
explicit review interface.
