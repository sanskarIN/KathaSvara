# KathaSvara v0.5.5 — WAV Doctor and Session Runtime Setup Developer Preview

**Experimental pre-release — NOT STABLE.** The Windows x64 executable is **UNSIGNED and UNBUNDLED**, **NOT A COMPLETE INSTALLER**, and does not include the Python/TTS dependency environment or speech model weights.

## What's new since v0.5.4

- **One-click offline WAV plumbing check:** desktop Settings can verify Python temporary PCM16 write, read-back and cleanup, reporting fixed failure stages without exposing private WAV paths. This is synthetic audio, not spoken Hindi.
- **Safer native diagnostics:** the desktop refuses contradictory/off-shape Python reports and never forwards arbitrary worker messages or private filenames as diagnostic text.
- **Choose runtime inside the desktop:** select an existing trusted Python executable and matching `services/inference` source folder for this app session. The choice can be cleared, is not saved in projects or localStorage, and only affects new jobs.
- **Improved first-use guidance:** actionable directions for missing Python/TTS packages, file access and model/API compatibility, while keeping all installations and model downloads explicitly under user control.
- **Regression coverage:** automated Python, TypeScript/React and Windows Rust checks protect the synthetic pathway, setup handling, privacy, and source/executable builds.

The executable does **not** include Python 3.11, NumPy, SoundFile, PyTorch, Chatterbox Multilingual or compatible model weights. Users need their own legitimate local model setup and may need to explicitly download approved dependencies. The presence of the app's UI and passing synthetic WAV tests does not establish that actual narration works.

**Not verified:** human listening of natural/intelligible Hindi, correct pronunciation, distinguishable character voices, real end-to-end audio/SRT output, or clean-Windows install and security acceptance.
