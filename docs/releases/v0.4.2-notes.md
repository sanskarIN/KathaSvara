# KathaSvara v0.4.2 — Experimental Hindi render preflight and cache-safety developer preview

**कथास्वर · Give Every Story a Voice.**

**This is an experimental developer pre-release, not a stable app, ready-to-run installer, or independently quality-checked Hindi narration service.**

## New since [v0.4.1](https://github.com/sanskarIN/KathaSvara/releases/tag/v0.4.1)

- **Model-free render plan inspector** in Characters & Scenes: inspect full Hindi dialogue or the selected scene before running a model. The report shows aggregate spoken-line count, text characters after pronunciation corrections and planned synthesis chunks; **no WAV or model weights are loaded by preflight**.
- **One validated narration preparation path:** selected speakers, scene/line scope, glossary-adjusted Hindi text and chunk boundaries are prepared once, then reused by synthesis. This helps prevent a mismatch between planned chunks, cache fingerprints and the rendered SRT text.
- **Consistent rendering controls:** full story, selected scene, forced regeneration and individual-line retry share a tested scope-selection contract. Invalid IDs, out-of-scope lines, unassigned speakers, empty speech and size-limit violations fail clearly.
- **Bounded cache reads:** before loading a cached mono PCM16 WAV into memory, its header is checked against the remaining 20-minute story duration, reserving any inter-dialogue pause. Symlinked cache entries are skipped before audio metadata inspection.
- **More model-free regression tests** across Python, TypeScript/React and Windows Rust, including cache limits and strict selected-scene scope.

## Windows EXE attachments

A successful exact-commit gated release attaches:
- `KathaSvara-v0.4.2-dev-win64.exe`: unsigned, unbundled Windows x64 developer executable (not a setup installer).
- `README.txt`: required local runtime configuration, installation caveats and security guidance.
- `SHA256SUMS.txt`: SHA-256 checksum for the EXE.

The gated workflow requires full Python 3.11 Ruff/pytest, frontend tests and build, Windows Rust tests/Clippy, Windows Python cache lock smoke tests, unsigned Windows EXE compilation and SHA-256 checks before AND after upload. It checks immutable tag creation from the exact current `main` commit. No prior tags are overwritten.

For model inference and speech playback the user still needs an independently set up **Python 3.11** environment, installed KathaSvara inference sources and Chatterbox Multilingual dependencies, separately authorized and installed voice-model weights, and compatible Tauri/WebView2 prerequisites. Configure `KATHASVARA_PYTHON` and `KATHASVARA_INFERENCE_DIR` to appropriate absolute paths. See [Windows developer setup](https://github.com/sanskarIN/KathaSvara/blob/main/docs/installation/portable-windows-candidate.md).

**Never bypass Windows security protection to run unsigned executables.** Verify the download checksum and use a trusted test environment.

## Not yet verified, therefore not stable

- Genuine Chatterbox Hindi pronunciation/naturalness, reproducible weights/hardware manifest, and distinct speaker identities have not received real listening acceptance. No voice-cloning or third-party recordings are bundled.
- Clean-machine interactive Windows desktop, full render/playback/export and install testing has not been accepted. There is no MSI/NSIS installer, signed binary, managed Python runtime or packaged model.
- WAV composition is limited to 20 minutes/256 spoken segments/100,000 source characters/500 model chunks. WAVs above the 25 MiB inline preview cap can be exported, not played inside the app.
- Dialogue SRT cue boundaries use measured PCM segment timings and reviewed text, not independent transcription or word alignment. Cancellation is cooperative and does not interrupt third-party inference inside an individual call.
- Advisory cache locks cover participating processes only; preflight predicts **text/chunk counts**, not inference resource usage or resulting audio duration.

The outstanding manual acceptance checklist remains in [GitHub issue #3](https://github.com/sanskarIN/KathaSvara/issues/3).
