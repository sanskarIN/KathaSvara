# KathaSvara v0.1.1 — Source-only Pre-release Acceptance

## Publication criteria

- [x] Existing v0.1.0 source-only developer pre-release is live as a separate, immutable version.
- [x] Python dependency discovery / diagnostics implemented without model loading.
- [x] Diagnostics are available through CLI, Rust bridge, and React Settings panel.
- [x] Diagnostic tests simulate both installed and missing optional packages.
- [x] Python, React, Rust and Tauri metadata updated to v0.1.1.
- [x] Release notes clearly identify the experimental, source-only nature and limitations.
- [ ] **Final tagged-commit CI succeeds** (Ruff, pytest, React tests/build, Windows Rust tests/Clippy).
- [ ] GitHub `v0.1.1` exists, and the GitHub API confirms `prerelease=true`.
- [ ] GitHub source archives downloadable. **No untested binary assets**.

## Out of scope for a source-only developer pre-release

- [ ] Install compatible upstream TTS weights and synthesize a natural Hindi smoke sample with documented model revision/hardware.
- [ ] Verify narration audibly for pronunciation, non-silence, timing, and artifacts.
- [ ] Launch the full desktop on Windows 11 and test import, project persistence, real synthesis and WAV export.
- [ ] Design, build, test, and checksum self-contained desktop installers.
- [ ] Persist a supervised model worker across jobs with cancellation and safe process termination.
- [ ] Benchmark real latency and memory on representative CPUs and GPUs.

Do not claim these unchecked items are complete in the release announcement. Keep the source-only release available to developers while quality and packaging work continue.
