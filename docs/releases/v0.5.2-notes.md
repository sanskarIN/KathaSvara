# KathaSvara v0.5.2 — Experimental Hindi Subtitle Review & Recovery Developer Preview

**Release note draft for a manually gated candidate.** Do not treat this document as evidence that v0.5.2 has been published. The GitHub release exists only if the exact-SHA v0.5.2 workflow explicitly passes and publishes the tag and three downloadable assets.

> **PRE-RELEASE / NOT STABLE.** KathaSvara remains an experimental, local-first Hindi production studio. Its prospective unsigned Windows x64 executable is **not** a packaged installer: Python 3.11, approved Chatterbox dependencies/weights, compatible Windows WebView2 and model setup must be supplied separately. Do not bypass security protections to run an untrusted download. **Real Hindi pronunciation, distinct character voices, accessible end-user installation and clean-Windows playback are still unverified** in [issue #3](https://github.com/sanskarIN/KathaSvara/issues/3).

## Improvements since [v0.5.1](https://github.com/sanskarIN/KathaSvara/releases/tag/v0.5.1)

- **Creator-facing Hindi subtitle cue preview:** view exactly the measured dialogue-level cues and glossary-adjusted render text in the Character and Scene Studio before exporting SRT. Browse ten at a time and seek compatible inline WAV playback to individual cues.
- **Local subtitle search:** search within already generated dialogue captions and see matching cues with their original numbers. Search does not change exported SRT text, create files or satisfy manual audio-review checklists.
- **Tighter subtitle correctness checks:** the same validator for preview and export rejects duplicate cue identifiers, unknown story segments, invalid ordering, non-printable characters and cues beyond the WAV's reported duration (allowing small frame-to-millisecond rounding differences).
- **Privacy-safe recovery diagnostics:** expose only fixed categories of interrupted or failed render attempts; do not echo custom exception names, model secrets or filesystem paths as a history explanation.
- **Safer progress/cancellation markers:** use exclusive cancellation marker creation and randomized, exclusive progress-sidecar files; reject pre-existing symlink/directory/oversized cancellation markers; preserve previous progress on failed replacement.
- **Updated local documentation and verification:** Windows/Hindi manual acceptance instructions, source-vs-release distinctions, GitHub Pages version announcement, mocked desktop UI and subtitle regression tests.
- **Guarded pre-release process:** Python/Ruff, React/Vitest and production build, Windows Rust/Clippy, model-free Windows Python filesystem tests, and Windows unsigned EXE compilation. Checks passing do **not** prove audible Hindi narration.

## Intended release assets (only after successful manual publication)

1. `KathaSvara-v0.5.2-dev-win64.exe` — unsigned Windows x64 **developer executable**, not an installer.
2. `README.txt` — explicit runtime requirements, security limits and model licensing disclosure.
3. `SHA256SUMS.txt` — SHA-256 digest for verifying the downloaded executable.

Check the exact released EXE against `SHA256SUMS.txt` with Windows PowerShell `Get-FileHash -Algorithm SHA256`. A missing or mismatched companion file means the release has not passed the expected verification. Do not assume the source branch's EXE candidate is the published release binary.

## Model and licensing boundaries

KathaSvara source code is under MPL-2.0. Chatterbox, PyTorch, checkpoints, speech datasets, third-party dependencies and any reference audio have independent terms and download requirements. No weights, proprietary voice samples, model server, GPU runtime or external Python environment are bundled.

## Known limitations and required human acceptance

- Distinct character identities have **not** been verified by listening; adding a named character does not establish a separate voice.
- Cue times are measured by rendered dialogue segments, **not** forced word alignment or proven perfect subtitle synchronization.
- The optional review checklist is a creator's note, **not** machine-verified natural-Hindi quality.
- The Windows executable candidate is unsigned, unbundled and requires manual environment configuration.
- No stable release or clean-device success should be announced until the manual [Windows/Hindi acceptance checklist](../qa/windows-hindi-acceptance.md) is completed and documented in issue #3.
