**NOT STABLE. NOT PUBLISHED. NOT A COMPLETE INSTALLER.**

Use the same source SHA and no-model test pipeline before authorizing a public
experimental prerelease. This does not certify any real Hindi TTS/STT

listening; keep https://github.com/sanskarIN/KathaSvara/issues/3 and

## Test the complete release pipeline without publishing

1. Open [the manual v0.5.7 workflow](../../.github/workflows/release-v0.5.7.yml)
   in GitHub Actions on the **main** branch. Confirm the current SHA of main
   after all intended source PRs have merged.
2. Select **Run workflow**. Enter that exact 40-character lowercase SHA in
   `release_sha`.
3. Leave `publish_release` set to **false** (its safe default). This still
   validates the predecessor tag, manifest versions, Python, React, security
   audit (once the dedicated release-security job is merged), Windows Rust
   and Windows unsigned EXE build. A successful workflow run does **not**
   create a v0.5.7 tag or GitHub release.
4. Inspect the resulting `kathasvara-v0.5.7-release-assets` Actions artifact.
   It should contain `KathaSvara-v0.5.7-dev-win64.exe`, `README.txt` and
   `SHA256SUMS.txt`. Match the SHA-256 sum with the exact downloaded EXE.
   Inspect Windows PE and WebView2 registration with the read-only helper;
   these do not prove that the desktop UI, microphone or real Hindi audio work.
5. Record the workflow run URL and the exact commit. Do not paste private
   audio, model paths, transcripts or credentials into public reports.

Only after explicit owner approval of the **current exact main SHA** should
someone deliberately dispatch the same workflow with `publish_release=true`.
The guarded publish job then verifies immutable tag/asset conditions and
downloaded GitHub SHA-256. Never treat a skipped publish job in validation-only
mode as publication.

The pre-release is **UNSIGNED, UNBUNDLED** and requires separately configured
Python 3.11, Chatterbox, optional faster-whisper, and authorized model weights.
Model-free checks never demonstrate real Hindi audio quality.
