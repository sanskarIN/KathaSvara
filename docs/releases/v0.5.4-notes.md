## Scope since v0.5.3

- **One actionable setup step:** a local, model-free Python TTS preflight returns a deterministic `next_action_code` and fixed, path-free advice for the first blocking issue: Python 3.11, broken optional imports, invalid CPU/device or V2/V3 settings, unsafe/invalid consented reference WAV, or unavailable/unverifiable optional Chatterbox APIs.
- **Windows first-use improvement:** `scripts/windows/launch-with-audio.ps1 -DoctorOnly` reaches the import probe even when packages are not installed, rather than aborting before explaining how to repair them. `-InstallDependencies` is a separate user-selected package installation action; `-DoctorOnly` never downloads or loads model weights.
- **Desktop Settings integration:** display a specific suggested repair without revealing private paths. An older external Python inference tree without `next_action` receives a safe compatibility message rather than `undefined`.
- **Regression coverage:** priority rules, invalid private configuration values, simulated React/Tauri no-inference interactions, Windows PowerShell 5.1 ASCII constraints, and missing-package fallthrough are covered by model-free tests. No test claims human audio acceptance.
- **Published-history accuracy:** manual Windows/Hindi QA instructions reference the real v0.5.3 release and preserve blank real-listening outcomes.
