# KathaSvara v0.5.0 — Model-free per-scene production audit (development)

**Status:** active development only. No v0.5.0 tag or executable release has been published. The preceding v0.4.2 pre-release remains independently gated through its exact-SHA workflow; do not merge this work until that workflow is finished.

## New capabilities in this batch

- Add **Audit scene readiness (no model)** to Characters & Scenes. In one inspection, see whether each scene can begin a Hindi dialogue render with existing character assignments and pronunciation controls, plus whether the combined story meets the whole-render limits.
- Share validation with the existing trusted, model-free `prepare_render_plan`. Each scene is checked independently, so a missing speaker in one scene does not disguise a valid independent scene.
- Report count-only readiness results and **fixed reason codes**: `ready`, `no_dialogue`, `unassigned_speaker`, `over_limit` and `needs_review`. The IPC JSON report does not include story text, pronunciation substitutions, character names, voice parameters or scene titles. The React view locally associates scene IDs with existing labels.
- Distinguish a project containing individually renderable scenes from one too large to render as a single 20-minute/256-line job. No actual audio duration can be predicted.
- Add mock/model-free Python tests for valid scenes, unknown speakers, stage directions, empty stories, per-scene vs full-story limits, strict payload validation and privacy of response data.
- Wire the audit through Python CLI -> Rust/Tauri command -> React, with stale-result invalidation on project changes and a clear warning that synthetic voice quality has not been verified.

## Remaining work toward a broader v0.5.0 milestone

- Expand production planning to include per-scene export naming, user-review checklist and reproducible model/hardware details **without automatically collecting sensitive recordings or prompt content**.
- Add browser component tests to cover real UI behavior and active render state, not just model-free backend contracts.
- Investigate an opt-in and inspectable production manifest export, limited to metadata selected by the creator and safe to share.
- Verify actual Chatterbox multilingual Hindi inference and clean Windows setup before any stable release; tracked in [issue #3](https://github.com/sanskarIN/KathaSvara/issues/3).

## Guardrails

- No model weights, generated voice samples, distinct-character speech promise, automatic resumable rendering, installer or signed binary in this development batch.
- A model-free readiness report is a **script structure and render-limit check**, not proof of TTS installation, human-approved captions or natural Hindi pronunciation.
