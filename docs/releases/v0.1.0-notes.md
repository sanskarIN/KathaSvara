# KathaSvara v0.1.0 — Developer Preview

**This is an early, source-only pre-release for developers and testers, not a production-ready Hindi narration application.** No Windows installers, standalone executables, model weights, sample narration, or rendered audio are included.

## What's available in this preview

- Hindi-first story editor with light and dark appearance and a local JSON project library.
- Bring your own UTF-8 TXT or Markdown story, review normalized Devanagari text and proposed speech chunks before starting synthesis.
- Experimental local Hindi speech adapter for **Chatterbox Multilingual TTS** with supported expressiveness and CFG guidance controls.
- WAV PCM16 generation, in-app audio preview, save-to-file control and cached-preview clearing. These interfaces have been unit-tested in isolation, but full real-model playback has **not** yet been confirmed.
- Rust/Tauri 2 native bridge, Python inference service, and React/TypeScript frontend.
- Test suites and CI configuration for Python, TypeScript, and Rust.
- Automated tests for the actual Python CLI text-inspection protocol, plus strict Rust Clippy lint validation.

## Getting started (developers)

1. Download the **Source code (zip)** or **Source code (tar.gz)** archive attached automatically by GitHub, or clone the repository and check out the `v0.1.0` tag.
2. Follow the setup in [README](../../README.md) and [development installation guide](../installation/development.md).
3. Install a compatible Python runtime and Chatterbox speech dependencies; initial model download may need internet and significant storage.
4. Start the React/Tauri desktop in **development mode**. The native desktop runtime is not yet distributed as a self-contained app.
5. Use *Check Python bridge* and *Inspect Hindi pronunciation text* before attempting generation.

## Known limitations / important warnings

- **Real Hindi narration is not acceptance-tested.** Hindi pronunciation, naturalness, timing, voice consistency and actual end-to-end Chatterbox output must still be verified by listening on suitable hardware.
- **No standalone desktop installer** is supplied. The Python inference process and model dependencies require manual setup.
- Only one narrator/voice-adapter pathway is exposed; this is **not** a multi-character audio drama editor, a music producer, or a production audiobook engine.
- Generation is limited to **3,000 Unicode code points per request**; first run can download model weights and may be resource-intensive.
- Generated audio is processed locally after model installation. Third-party Chatterbox weights/dependencies are not licensed under KathaSvara's MPL-2.0; review their licenses separately.
- **Do not use this preview for critical narration or claim studio-quality results.**

## Validation

This pre-release is configured to be published only if **Python checks, React tests/build and Windows Rust tests/Clippy** pass on its tagged source commit. These automated checks do **not** validate a real user-facing Windows launch or the quality of synthesized Hindi.

For outstanding manual acceptance steps, see [v0.1.0 checklist](v0.1.0.md) and [tracking issue #1](https://github.com/sanskarIN/KathaSvara/issues/1).
