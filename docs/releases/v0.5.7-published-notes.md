# KathaSvara v0.5.7 — Experimental Offline Hindi STT Developer Preview

> **NOT STABLE / NOT A COMPLETE INSTALLER.** This is proposed copy for a
> separately approved manual prerelease. A file in the repository is not
> proof of actual GitHub publication.

## What is new since v0.5.6

- Optional offline Hindi STT with a separately installed multilingual
  faster-whisper/CTranslate2 checkpoint, from a short selected WAV or a
  consented 30-second microphone capture.
- Safer local model setup and WAV signal checks, no automatic STT downloads,
  protected recording integrity, fixed errors and private scratch recovery.
- Editable/correctable Hindi transcript review with explicit approval before
  insertion into the story editor.

## Files

- `KathaSvara-v0.5.7-dev-win64.exe` — **UNSIGNED** experimental Windows
  desktop executable, **NOT A COMPLETE INSTALLER**.
- `README.txt` — runtime and installation limitations.
- `SHA256SUMS.txt` — EXE digest for local verification.

Python 3.11, Chatterbox and optional faster-whisper, external model weights
and Windows/GPU runtime are **not bundled**. TTS libraries or model weights
**may download** after consent; STT never silently obtains a model.

Passing a build/test does not certify Hindi intelligibility, recognition
accuracy, distinct character voices, microphone permissions, speaker playback,
WAV/SRT correctness or clean Windows 11 installation. Please record manual
results under [issue #3](https://github.com/sanskarIN/KathaSvara/issues/3),
[STT #142](https://github.com/sanskarIN/KathaSvara/issues/142) and
[activation #129](https://github.com/sanskarIN/KathaSvara/issues/129).
