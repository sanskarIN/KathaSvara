## Proposed changes since v0.5.4

- **Model-free WAV I/O doctor:** a disposable 250 ms PCM16 WAV is written, structurally inspected and removed. It does not use speech models, speakers or microphone, and never saves a private story or voice recording.
- **Desktop Settings integration:** a one-click WAV diagnostic provides safe, fixed failure stages and actionable repair guidance. Native Rust validates the returned report and rejects false model/Hindi/playback claims and untrusted error text.
- **Session runtime selection:** choose an existing trusted Python interpreter and matching `services/inference` folder through local dialogs without editing global environment settings or saving private paths. This applies to newly launched Python jobs and can be cleared.
- **Source-level regression checks:** Python synthetic WAV tests, mocked React interactions and Windows Rust tests protect privacy, cancellation and setup validation.

## Distribution limits

If this preview is authorized and its guarded workflow passes, it will include an **UNSIGNED, UNBUNDLED** Windows x64 `KathaSvara-v0.5.5-dev-win64.exe`, `README.txt` and `SHA256SUMS.txt`. **NOT A COMPLETE INSTALLER.** No Python 3.11, Chatterbox, PyTorch or model weights are bundled. Users must independently install compatible, approved dependencies and consent to any external downloads. The app's new session selection does not install the runtime or prove it can generate speech.

Actual intelligible Hindi narration, naturalness, distinct character voices, real output playback, subtitle timing on model output, and a clean Windows 11 machine are still **not tested** and remain open in [issue #3](https://github.com/sanskarIN/KathaSvara/issues/3) and [full activation issue #129](https://github.com/sanskarIN/KathaSvara/issues/129).
