# v0.2.0 Architecture — Hindi Drama and Scene Production

**Status:** Developer branch only, not a published release. This module is intended to preserve the v0.1.x narrator editor while adding a structured dramatic script.

## Version 2 document contract

The Python `kathasvara.story` module and TypeScript `src/lib/story_v2.ts` define compatible characters, scenes and segments. Tauri's `StoryV2` performs a second validation before any disk write. A story retains its original `text` alongside parsed scenes so narrator dialogue is never silently rewritten.

- `schema_version: 2`, `id`, `title`, `text`, `characters`, `scenes`
- Character: stable ID, name, description and `voice`
- Voice: supported `chatterbox-multilingual` Hindi engine parameters (`exaggeration`, `cfg_weight`), `model_id`, `pause_ms` and profile version.
- Scene: ID, title, notes, ordered segments.
- Segment: ID, original text, previewable spoken text, resolved `speaker_id` (or unresolved `source_label`), kind `speech` or `direction`, status, optional audio reference and measured duration.

Real independent voice identity and reference conditioning are not enabled until upstream model APIs and consent/licensing are verified. A character's independent configuration is **not** an independent voice.

## Labeled dialogue syntax

Use explicit tags at the start of lines:

```text
# दरबार
Narrator: बहुत समय पहले धार नगरी में राजा भोज रहते थे।
[दरबार में शंख बजता है]
राजा भोज: मंत्री जी, प्रजा की स्थिति कैसी है?
मंत्री: महाराज, सब कुशल हैं।
---
# जंगल
राजा भोज: आज हमें किस दिशा में चलना चाहिए?
```

- `Narrator:`, `वाचक:`, and `कथावाचक:` are narrator aliases.
- Other labels must match character names (case-insensitive) or remain unresolved, marked by their original label. Users must correct labels in the UI before rendering.
- A paragraph without an explicit label is conservatively treated as narrator text; no semantic speaker inference is attempted.
- `---` or Markdown scene headings introduce a new scene.
- Bracketed lines like `[दरबार में शंख बजता है]` remain stage directions and are not sent to speech generation.
- Text following a labeled line is treated as a continuation until a new label or blank paragraph.
- The parser returns stable UUID5 scene and segment IDs for a fixed source script ID; reparsing after edits may change index assignments, so preview cache is invalidated in the UI.

## Storage and migration

The old Tauri `save_project`, `load_project`, `list_projects` commands and `projects/` data files remain unchanged.

- `save_story_v2` and `load_story_v2` use `projects-v2/{UUID}.json`.
- V2 JSON writes are bounded, validated and atomic.
- Python `migrate_legacy` converts a legacy story `{id,title,text}` to a non-destructive document with narrator and no parsed scenes.
- Existing projects are not overwritten or deleted by reading their v1 metadata. A human must explicitly save a v2 document through the scene editor.
- Character deletion reassigns affected segments to the narrator and clears potentially stale audio information.

## Audio architecture

The Python `kathasvara.production.render_story` function:

1. Validates document and unresolved-speaker assignments before loading a model.
2. Loads the authentic upstream model once per render, not once per line.
3. Splits speech conservatively on Hindi sentence/word boundaries without silent truncation.
4. Routes only supported engine parameters and does **not** assert distinct voices.
5. Caches valid mono PCM16 WAV segments by text/model/settings fingerprint, unless regeneration is requested.
6. Adds bounded pauses and short fades at generated chunk boundaries to reduce clicks.
7. Computes duration from real sample lengths and checks the final WAV metadata.
8. Saves the final rendered file atomically, preserving verified cache items across recoverable failures.

The Tauri `render_story_v2` command dispatches the Python process in a blocking worker, writes progress status to a UUID-scoped app-data file, and returns validated WAV bytes for a local preview. `story_render_progress` polls completed segment counts; `cancel_story_render` writes a UUID-scoped sentinel. Cancellation is **cooperative between model chunks**—it cannot interrupt an ongoing opaque `model.generate` call instantly. Current desktop preview remains limited to 25 MB; CPU/GPU capabilities and real Hindi narration must be measured rather than guessed.

## Binary-build experiment

The `Windows developer executable candidate` workflow attempts `tauri build --no-bundle` and, only if compilation succeeds, uploads an unsigned `.exe` to the workflow's 14-day artifacts with a checksum and an explicit dependency warning. This is **not** a self-contained public installation package. It requires a separately installed Python environment and inference source directory configured with `KATHASVARA_PYTHON` and `KATHASVARA_INFERENCE_DIR`.
